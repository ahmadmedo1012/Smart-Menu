# DESIGN.md — the Smart Menu design language

> code — follow them; change them only deliberately and update this file in the
> same commit.
>

## Identity — «Warm Culinary Editorial» (Phase 5, r152)

Smart Menu is the ecosystem's **menu**: paper, plates, and printed-menu
typography. Phase 5 deliberately breaks the Madarek night monoculture —
this product's contract is its own:

- **LIGHT-first.** `:root` is the light theme; `.dark` («مطبخ ليلي دافئ» —
  warm night kitchen) is the explicit opt-in (next-themes
  `defaultTheme="light"`, one resolution path with the pre-paint
  `THEME_BOOT_SCRIPT`; `enableSystem` OFF).
- Ground cream `#FBF7F0` · raised `#FFFFFF` · soft `#F4EDE1` · espresso ink
  `#241811` · secondary `#6B5D4F` (5.95:1) · hairline `#E8DECE`.
- Primary **TERRACOTTA** `#C2452D` (white fg 5.02:1 · hover `#A93A26` ·
  pressed/strong `#8A2B1D` · as TEXT `--accent-ink #8A2B1D` 8.05:1) · warm
  amber `#B7791F` **sparingly** (highlight ink `#7A5210` 6.46:1).
- The warm night kitchen: ground `#1D1410` espresso night, surfaces
  `#2A1E15 / #241A13 / #2E2118`, cream ink `#F7EFE2`, luminous terracotta
  `#E07856` (6.03:1 text · fg `#2A130D` 5.84:1) · pressed `#C2452D`.
- Status families keep the semantic token NAMES (150+ TSX consumers, zero
  churn) but are warm-graded: **sage** success (`#6FA06A` / ink `#2E5230`) ·
  **amber** warning (`#B7791F` / ink `#7A5210`) · **warm-steel** info
  (`#6B8CA3` / ink `#2E4A5C`) · **deep-rose** destructive (`#C96873` / ink
  `#8E2F3D`). Never raw green/red/blue.
- **WhatsApp green is reserved for WhatsApp UI only** (`--whatsapp #25D366`
  constant; text-on-fill rides `--whatsapp-ink` per theme).

**Brand signature**: the QR-corner mark (`.qr-corner`) carries the terracotta
metal gradient `linear-gradient(145deg, #C2452D, #8A2B1D)` with the CONSTANT
cream glyph `#FBF7F0` (5.0:1 on the metal). `text-gradient-orange` /
`text-gradient-hero` ride the same pair. Raster brand assets
(favicon/icon-192/icon-512/apple-touch-icon/brand-icon + `src/app/favicon.ico`)
are regenerated by `scripts/r152-regen-brand.mjs` (sharp, terracotta plate);
the social card (`public/og-default.png`) renders from
`scripts/og-template.html` — cream ground, espresso ink, terracotta metal,
Baloo display (regenerate via `scripts/render-og.mjs`). PWA chrome:
`lib/brand.ts` `BRAND_THEME_COLOR*` (#FBF7F0 / #1D1410) + manifest.json +
`ThemeColorSync` runtime re-point — the four must stay in sync.

## Color

- **Tokens only.** Raw palette classes and arbitrary hexes are banned outside
  the token files (sanctioned raw-hex sites: WhatsApp brand colors, recharts
  selectors, device-mockup materials, the print sheet's own scoped
  `--print-*` block, the offline/404 inline-style shells which must survive
  with no CSS). Audit before adding any.
- **Neutral ramp** (light): `#FFFFFF` raised · `#FBF7F0` ground · `#F4EDE1`
  soft · `#EFE6D6` deeper paper · `#E8DECE` warm hairline · `#D8CBB2`
  divider · `#A08D74 / #8A7A68` muted tiers · `#6B5D4F` secondary ·
  `#3E332A` · `#241811` espresso ink. Night twin: espresso-brown ramp to
  cream `#F7EFE2`. **No cold grays anywhere** — even shadows are
  espresso-tinted `rgba(64,46,28,*)`.
- **9 section families** × {bg, ink, deep} in BOTH modes: peach · mint ·
  lavender · sky · yellow · rose · sand · grey · copper (`--c-*-bg/-ink/-deep`).
  Light = warm pastel bgs + saturated inks + deep text shades (all ≥6:1);
  night = espresso-tinted deep bgs + luminous inks. The copper family IS the
  terracotta identity (`#F7E2D9 / #C2452D / #8A2B1D` light).
- **Status language = semantic tokens** via `lib/order-status.ts` (SSOT):
  `warning` amber = new/pending · `info` warm-steel = preparing · `success`
  sage = ready/completed · `destructive` rose = cancelled. Canonical split:
  base = the family ink (fill/stroke), `-soft` = pastel bg tint, `-ink` = the
  family DEEP for TEXT (light) / the luminous ink (night). Fill foregrounds =
  espresso `#241811` on light mids · `#2A130D` on night luminous fills.
- **Charts** read the `--chart-1..8` roster at draw-time
  (`components/shared/chart-tokens.ts`); SSR fallbacks = the LIGHT roster.

## Typography

- **BODY = IBM Plex Sans Arabic** (self-hosted 400/500/600/700 ×
  {arabic, latin} subsets, `font-display: swap`, arabic 400+700 preloaded in
  both root layouts). Long-form menu readability keeps the Plex voice.
- **DISPLAY/HEADINGS = Baloo Bhaijaan 2** (self-hosted variable 400-800,
  declared 600/700 × {arabic, latin}; arabic 700 preloaded in both root
  layouts + the SW precache). `--font-display` / `--font-heading` =
  `"Baloo Bhaijaan 2", "IBM Plex Sans Arabic", …`; h1-h5 ride
  `var(--font-heading)` at TRUE 700. `--font-sans` / `--font-arabic` stay
  Plex-led — the culinary voice is display-only.
- Accent cuts: Plex Mono (latin) for codes/IDs. The legacy `--font-cairo`
  shim still resolves to "IBM Plex Sans Arabic" (zero-churn safety net).
- Weights ≤ 700 (`--fw-black` = 700).
- **No letter-spacing on Arabic, ever** — the `[class*=tracking-]` guard in
  globals.css enforces it; tracking is legal only on Latin-safe runs (mono,
  `dir="ltr"` URLs). No synthetic italics on Arabic either.
- Numbers everywhere: `tabular-nums` + `lining-nums` globally (this is a
  numbers product — prices, counts, invoices).

## Shape, space, elevation — «plate-round»

- Radius ladder: **10 / 12 / 14 / 16 / 20 / 24 / 28** (+ `9999` pills) via
  `rounded-*` (`--r-xs … --r-3xl`). **16 (`rounded-lg` / `--r-lg`) is the
  default card plate** — the shared Card + `.card-premium` consume it; the
  Card's first/last image crops follow (`rounded-t-lg` / `rounded-b-lg`).
  Warmer and rounder than the old Notion-soft 6..28; never ad-hoc px radii.
- Spacing: Tailwind scale only (zero arbitrary px — keep it that way).
- Elevation: light = soft two-layer **espresso-tinted** (rgba(64,46,28,*));
  night = fill-led + 1px inset warm top-light (`--shadow-card/-h/-pop/-modal/
  -mockup` + the `-premium` pair compose on top). Glass: 16px blur + warm
  hairline (`--glass-*`).
- Under `prefers-contrast: more`: elevations collapse to solid warm rings,
  borders strengthen, glass goes solid.

## Signature motifs (the Phase 5 voice)

- **The menu dot-leader** — the printed-menu price leader. `.menu-leader`
  (flex row) + `.menu-leader-rule` (flexing `2px dotted var(--menu-leader)`
  — warm tan `#CBB08C` light / `#57402D` night). Rides the item card price
  row, the order-dialog quantity card, the cart line items, the slide-over
  totals, and the print sheet's own `.ldr` twin. Don't remove it from those
  surfaces — it's parity-pinned.
- **Warm food-imagery grade** — text-on-image photos bottom into an
  ESPRESSO scrim, never cold black: `.warm-scrim` (cards) /
  `.warm-scrim-strong` (order dialog) / `.warm-scrim-faint` (gallery).
  Consistent crops: `aspect-[4/3]` item images, plate-round corners from the
  card, hero logos square in glass orbs.
- **Category pills** — the filter strip (CategoryTabs) is pill-first
  (`rounded-full`, terracotta active plate via `bg-orange`, motion
  `layoutId` spring), counts in chip wells.
- **The brand mark** — terracotta metal + cream menu-glyph (see Identity).

## Components

- Primitives (`src/components/ui/*`: button, input, select, sheet, dialog,
  card, badge, table, switch, label, separator) are the default choice —
  never re-implement a primitive. Input canon: 44px (`h-11`) · 16px text
  floor at every breakpoint · halo-only focus · AA placeholder.
- **Empty states**: use the `EmptyState` component — don't add hand-rolled ones.
- **Loading**: `Skeleton` (shimmer) for shape placeholders; `animate-pulse`
  only for live status indicators.
- **Toasts**: `premiumToast` (`lib/premium-toast.tsx`) — 28px pastel icon
  wells + `-ink` glyphs + 1px status hairline; error/trash are
  manual-dismiss `role=alert`. Fallback inks = the LIGHT roster.
- Icons: lucide named imports only. Directional icons in RTL get
  `rtl:rotate-180`; **back affordances use ArrowRight/ChevronRight** (RTL
  convention, documented at print/page.tsx).

## Motion

Unchanged ladder (theme-independent): `--t-micro 80 / --t-fast 160 /
--t-base 240 / --t-slow 380 / --t-slower 520 / --t-cinema 720ms` + semantic
layer (page 320 · reveal 360 · stat 700 · skeleton 1200ms) + easings/springs.
Press register: buttons `scale(0.97)`, cards `scale(0.99)` with 80ms snap-back;
hover lift only on real pointers. Above-fold hero uses `animate-rise-in`
(transform-only). Infinite ambient motion (orbs) is viewport-gated +
reduced-motion-hidden. No scroll-hijacking on operational surfaces.

## Layout & z-layers

- z-band registry at the top of globals.css (base → sticky → dropdown →
  drawer/header → modal → toast → popover → live-toast → overlay → max).
  Sticky/float band z-30/31/33 (`--z-float`); dialog/sheet band z-40/50 —
  floats NEVER cover modals (the r121 J-1 tap-hijack lesson).
- Sheets use `dvh` (not `vh`) — iOS URL-bar safe.
- Numeric/bidi content (phones, IBAN, order numbers) gets `dir="ltr"` or
  `bdi` isolation; Arabic labels render `dir="auto" text-start`.

## Accessibility layers

- **High-contrast mode** (manual opt-in): `html.high-contrast` (the LIGHT
  default layer) + `html.dark.high-contrast` (the night layer) — AAA text,
  3:1+ borders, 112.5% base type, 3px focus outlines; pre-paint boot script
  in both root layouts.
- **prefers-contrast: more**: automatic — `:root` (light) collapses to warm
  espresso solid rings; `html.dark` to luminous cream rings.
- **Reduced motion**: two-layer belt — universal 0.01ms clamp + token
  zeroing + per-class off-switches; framer-motion rides
  `MotionConfig reducedMotion="user"`.

## Mode rule (I-12)

Persuade surfaces (landing) may carry the full terracotta identity
(gradients, showcase, the «المائدة» board). Operate surfaces (owner/admin
CRUD) get a thin header accent AT MOST. Never port marketing ambience into
CRUD density.

## Offline / PWA

`public/offline.html` carries the culinary pair inline (cream ground,
terracotta CTA, warm night dark media block). The SW (`public/sw.js`,
`smart-menu-v9`) precaches offline/manifest/icons + Plex arabic 400/700 +
**Baloo arabic** (the h1 voice survives offline); protected navigation HTML
is never cached. Bump CACHE_NAME on any SW-adjacent change.

## SEO/metadata conventions

Title template `%s | المنيو الذكي`; page titles never repeat the brand suffix.
Per-restaurant menus get unique meta + Restaurant JSON-LD (real data only).
Auth surfaces + print are noindex. Social cards point at `/og-default.png`
(1200×630, culinary identity — regenerate via `scripts/render-og.mjs` after
any template change).

## Anti-patterns (do not resurrect)

- The Madarek night monoculture (indigo `#070B16` ground, gold `#E9B44C`,
  sand `#F2EFE6`, night-first default) — retired for THIS product; only
  "was …" migration comments may mention those hexes.
- Cold grays (any neutral with a blue/violet cast) — the whole world is
  warm: ink, hairlines, shadows, scrims.
- Raw green/red/blue for status — semantic tokens only.
- WhatsApp green outside WhatsApp UI; cold-black scrims on food imagery
  (use `.warm-scrim*`); night-gold gradients on product chrome.
- Letter-spacing on Arabic; synthetic Arabic italics; ad-hoc px radii.
