## 1. 🔴 نافذة التقييم مقصوصة + لا تُغلق + النجوم تختفي (commit 089f7b3d)
### السبب الجذري (محاكاة + كود)
- `ReviewSheet` كان `overflow-hidden` مع `max-h-[85vh]`
- عندما يزيد المحتوى (تقييمات/نموذج)، **كل ما يتجاوز 85vh يُقص بلا تمرير**
- النجوم + زر الإرسال + التقييمات تختفي خلف الحافة
- (زر الإغلاق ظاهر لكن المحتوى القابل للقراءة مقصوص)

### الإصلاح
- `overflow-hidden` → `overflow-y-auto overflow-x-hidden`
- **مؤكد حياً**: `overflowY: auto` + زر إغلاق + Escape يعمل

## 2. 🔴 حقول الاسم/الهاتف في الطلب (commit 089f7b3d)
### القرار (بطلب المستخدم)
- العميل يطلب مباشرة عبر واتساب — لا حاجة لاسم/رقم
- **أُزيلا** من صفحة /cart — بقي "ملاحظات الطلب" (اختياري) فقط
- **مؤكد حياً**: لا "الاسم (اختياري)" ولا "رقم الهاتف" + قسم ملاحظات يعمل

## 3. 🟡 تداخل نموذجي الطلب (محقق — لا خطأ)
### الفحص
- **CartSlideOver** (في المنيو): سلة منزلقة سريعة → زر "إتمام الطلب" → /cart
- **/cart**: النموذج الوحيد الكامل (أصناف + نوع طلب + ملاحظات + مراجعة)
- **لا نموذجين متداخلين** — تدفق واحد نظيف (SlideOver يربط للصفحة)
- الـ "تداخل" الذي رآه المستخدم = تكدس الاسم/الهاتف + ملخص — أُزيل الحقلان فصار أنظف
