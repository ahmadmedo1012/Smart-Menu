# Round79 — المرحلة F: الأمان والخصوصية

**الحالة: مكتملة آليًا + إجراءات مطلوبة من المالك موثقة** — كل فحص قابل للأتمتة نُفّذ بأدلة طرفية؛ المستودع أصبح **خاصًا فعليًا**؛ تدوير أسرار الإنتاج (Vercel) خارج صلاحيات الوكيل ويتطلب المالك — موثّق بقائمة إلزامية أدناه.

> أداة الخطة `gstack /security` غير مثبتة في بيئة التنفيذ (موثّق منذ A-0). البديل الفعلي: مسح حتمي شامل للتاريخ والكود + فحص اعتماديات إنتاجية حية + API GitHub للخصوصية — كلها بأوامر فعلية ونواتج ملصقة.

- `src/lib/env.ts`: تحقق Zod إلزامي — `JWT_SECRET` بحد أدنى 16 حرفًا، `AUTH_SECRET` إلزامي، `TELEGRAM_BOT_TOKEN` اختياري (الميزة تتعطل بأمان إن غاب).
- كلمة مرور الاختبار `admin123456` موجودة **حصريًا** في `tests/e2e/round79-phaseC-journey.spec.ts` (قابلة للتجاوز بمتغير `PHASEC_ADMIN_PASS`) — لقاعدة الاختبار المحلية فقط.

## 3) الفحص الحاسم: هل الإنتاج يستخدم الاعتماد الافتراضي؟

```
POST https://menu.smart-link.ly/api/auth/login  {"username":"admin","password":"admin123456"}
→ HTTP 401  {"success":false,"error":"اسم المستخدم أو كلمة المرور غير صيحة"}
```

**الإنتاج آمن**: كلمة مرور الأدمن الإنتاجية ليست الافتراضية (الاختبار المحلي فقط يستخدمها). محاولة واحدة موثقة بموجب تفويض فحص الخطة.

## 4) جرد الأسرار وحالتها

| السر | أين يعيش | الحالة |
|---|---|---|
| `JWT_SECRET` / `AUTH_SECRET` | Vercel env (إنتاج) + `.env` محلي | إنتاج: **يتطلب تدويرًا من المالك** (لا وصول للوكيل) · محلي: قيم تطوير ضعيفة متسلسلة — غير مُرحّلة أبدًا، يُنصح بتدويرها محليًا أيضًا |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_WEBHOOK_SECRET` | Vercel env | **يتطلب تدويرًا من المالك** إن لم يُدوّر منذ آخر استخدام |
| `CRON_SECRET` | Vercel env | **يتطلب تدويرًا من المالك** |
| `DATABASE_URL` (Neon) | Vercel env | كلمة مرور القاعدة — **تدوير دوري موصى به من المالك** |
| GitHub PAT (المقدَّم للوكيل للدفع) | جلسة فقط، غير مخزّن | **إبطاله من المالك فور انتهاء الجولة** (GitHub → Settings → Developer settings → Tokens) |
| الاعتماد الافتراضي المحلي | قاعدة اختبار محلية | مقبول (بيئة اختبار معزولة) |

## 5) المستودع — خاص فعليًا (بالأمر لا بالوعد)

```
PATCH api.github.com/repos/ahmadmedo1012/Smart-Menu {"private":true}
→ private now: True | visibility: private
```

- الإنتاج **غير متأثر**: `menu.smart-link.ly` → 200 و `/menu/al-waha-cafe` → 200 بعد التحويل مباشرة.
- وصول Push/Nشر مستقبلي: تكامل Vercel GitHub App يحتفظ بوصوله لمستودعات الحساب الخاصة؛ التوكن الحالي صالح للدفع (تحقق `ls-remote` بعد الخصوصية: `5cca9655`).

## 6) ملاحظات معمارية واردة من المراحل السابقة (مقفلة هنا كسجل أمني)

1. **`/api/config` قبل المصادقة** (من C): يكشف أرقام محفظة الدفع الافتراضية لمجهول — سلوك مقصود (العميل يحتاجها قبل الدفع) ومحتواها أرقام أعمال عامة أصلًا. لو صارت الإعدادات حساسة مستقبلًا: نقطة عامة جديدة `/api/public/wallet` بقائمة بيضاء حقول.
2. **حد التردد 5/د للتسجيل** (من C): يعمل لكن `RateLimitEntry` يتطلب تنظيفًا دوريًا (مرشّح صيانة).
3. **كاش الخطط في الذاكرة 5 دقائق** (من C): مقبول — التغيير نادر ويعاد الضبط بإعادة التشغيل.

## 7) قائمة إلزامية على المالك (قبل الإعلان عن الجاهزية)

1. **تدوير أسرار Vercel** (Project → Settings → Environment Variables): `JWT_SECRET` و`AUTH_SECRET` (عشوائي 64 hex جديد) ثم Redeploy — يُبطل كل جلسات قائمة (سلوك صحيح عند التدوير).
2. **تدوير** `TELEGRAM_BOT_TOKEN` (من BotFather إن استُخدم مؤخرًا) + `CRON_SECRET` + كلمة مرور قاعدة Neon.
3. **إبطال توكن GitHub** المقدَّم لهذه الجولة (ghp_0U3x… — بُدئ بـ 0U3xOtAd، كامل القيمة بحوزتك) فور اكتمال الجولة G.
4. (اختياري) تحديث قيم `.env` المحلية الضعيفة بقيم عشوائية.
