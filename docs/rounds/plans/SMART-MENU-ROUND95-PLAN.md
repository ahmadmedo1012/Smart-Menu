## قواعد صارمة لكل وكيل
1. اقرأ `worklog.md` + `docs/smartbot-design-spec.md` قبل أي سطر.
2. **لا تلمس ملفات خارج ملكيتك**. لا git commit (المنسق وحده).
3. الألوان عبر الرموز فقط — لا hex في JSX.
4. الحفاظ على AA (§7 من المواصفة) — البوابة درجات موجودة.
5. التحقيل: `pnpm exec tsc --noEmit` + `pnpm exec eslint <ملفاتك>` — لا تشغّل خادم dev (المنسق/D يتكفلان).
6. ألحق قسمك بـ `worklog.md` (القالب الرسمي) بعد الانتهاء.
